## Done — style 6: Cozy Paper (`cozy-paper/`)

## Done — style 5: Clean Flat (`clean-flat/`)
The first light style: white cards on pale grey-blue, flat saturated colour, rounded, soft shadows, no outlines.
Accents darkened until a white label reads 3:1; the bright gold button carries a dark label and a dark glyph.
Nunito + Fredoka. Spec: `clean-flat/STYLE.md`. Ported from Fantasy RPG Casual. 30 components · 10 blocks · docs · bundle · 155 icons
(tab bars use the coloured nav set N1).

## Done — style 3: Fantasy RPG Casual (`fantasy-rpg-casual/`)

30 components · 10 blocks · docs · bundle (`dist/`) · 90 shared icons + extension set (see below).
Checks: selectors clean (9 reviewed exceptions), `--order` 0 differ, `check_theme --base` PASS.

## Done — style 2: Tactical Dark (`tactical-dark/`)
Dark, flat, cut corners, lit edges. Same class names, same `data-*`, same `sc.js` — only the CSS differs.
Structure mirrors `super-casual/kit` exactly, so the docs pages are portable between styles unchanged.

| | |
|---|---|
| Custom themes | `themes/` — contract (`README.md`), 3 example themes, live preview, `tools/check_theme.py`. Tactical Dark is fully token-driven; Super Casual is not yet |
| Bundle | `tactical-dark/dist/` — same file names as Super Casual, so a game swaps style by swapping the folder |
| Components | all 30 |
| Blocks | all 10 — ported from Super Casual, survival-theme content (`tactical-dark/kit/blocks/`) |
| Icons | 90 — 45 flat white glyphs, 45 painted colour items |
| Docs | one page per component + Icons gallery, generated by `tools/sync_style.py` |
| Spec | `tactical-dark/STYLE.md` — tokens, anatomy of the button, and the four rules that cost time to find |
| Prompts | `tactical-dark/kit/assets/ICON-SHEETS.md` — 10 sheets of 9, ready to regenerate the set |

New tooling, all reusable for a third style:
- `tools/sync_style.py` — copies sc.js + the docs renderer into a style, writes a docs page per skinned
  component, greys out the rest, and generates that style's registry and Icons gallery
- `tools/gen_icon_prompts.py` — writes the 10 sheet prompts
- `tools/sheet_to_icons.py` — cuts a 3x3 or 4x4 sheet into normalised icons (`--alpha` for sheets that
  already have their background removed, keeping colour)
- `tools/normalize_icons.py`, `tools/despeckle.py`, `tools/cut_bg.py`, `tools/gen_image.py`
