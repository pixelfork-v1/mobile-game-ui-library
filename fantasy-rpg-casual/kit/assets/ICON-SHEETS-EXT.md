# Icon sheet prompts — Fantasy RPG Casual, extension set

Everything the reference images show beyond the shared 90: the rest of the function glyphs (brand logos left out),
the two item boards and the crafting board, and the bigger shop art (chests in three states, gem and gold packs, pennants).
Generated by `tools/icon_batch.py fantasy-rpg-casual --all --skip-done` in the background; see run.log there.
Heading format: `## Sheet ID — title (COLSxROWS, WIDTHxHEIGHT, CANVAS)`; defaults 3x3, 1024x1024, 160.
